预警规则配置

规则配置分两层：单来源预警规则先成立，才允许被融合来源预警规则引用。当前阶段先实现和规划单来源预警；融合来源只展示规划，不生成。

规则清单

规则按清单落列；可新增、编辑、删除。每条规则只绑定一个主来源，例如指标、告警、SD、心声或变更。

规则编辑

除短周期突变外，必须对比“同一时段”的历史基线，避免把白天/晚上、上午/下午的业务量自然差异误判为异常。

判断逻辑：当前5/30分钟突变 + 前1天/近几天同一时段显著偏离，才提高预警置信度。

融合来源预警规则规划
当前阶段不生成融合来源预警，只规划配置逻辑。融合规则必须引用多个已经启用的单来源预警规则，当多个单来源预警都满足条件时才触发。

例如：T1/T2 应用 5分钟内 P95 ≥ 800ms 且持续 3次
+
单来源预警 B

单来源预警 C
例如：15分钟内心声故障语义反馈 ≥ 3人
→
融合来源预警
多个单来源预警在同应用/同业务域/拓扑邻近范围内同时满足，才生成融合预警。
